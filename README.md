# JsonLens

Editor y analizador de JSON **100% en el navegador**: validar, formatear, analizar y comparar.

## Puesta en marcha

```bash
npm install
npm run dev
```

App en `http://127.0.0.1:5173`

## Scripts

```bash
npm run dev      # desarrollo
npm run build    # producción
npm run lint     # ESLint
npm run preview  # previsualizar build
```
