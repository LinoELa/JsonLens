# @Architecture

Esta carpeta guarda la documentacion de estructura y reglas tecnicas del frontend `JsonLens`.

## Para que sirve esta carpeta

Sirve para documentar:

- arquitectura principal del frontend
- reglas de dependencias
- decisiones de organizacion de carpetas
- plan de evolucion del MVP

## Que tipo de archivos van aqui

Aqui encajan archivos como:

- arquitectura modular MVP del frontend
- reglas de dependencias entre UI, estado y API
- auditoria de estructura actual vs objetivo
- plan de migracion de estructura

## Que archivos NO van aqui

No deberian ir aqui:

- guias numeradas paso a paso
- referencia diaria (Git, HTTP status, etc.)

Esos documentos encajan mejor en:

- [`../guides/`](../guides)
- [`../Reference/`](../Reference)

## Idea principal

`Architecture` es la carpeta de reglas del sistema frontend.
