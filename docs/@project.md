## Que es `JsonLens`

`JsonLens` es una aplicacion web para trabajar con JSON de forma clara y visual.

Piezas del ecosistema:

- `JsonLens`: frontend React
- `adminJsonLens`: backend API

## Problema que quiere resolver

- JSON grandes dificiles de leer
- errores de sintaxis confusos
- comparaciones manuales lentas
- debugging de APIs con cambios frecuentes

## Vision del frontend

- pegar o cargar JSON
- validar
- formatear
- visualizar en arbol
- comparar dos JSON y ver diferencias

## MVP del frontend

1. entrada de JSON
2. validacion
3. formateo
4. vista en arbol
5. comparacion
6. diff visual basico
