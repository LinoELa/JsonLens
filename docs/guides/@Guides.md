# @Guides

Esta carpeta guarda documentacion guiada y secuencial del frontend `JsonLens`.

## Para que sirve esta carpeta

Sirve para explicar el recorrido de construccion del frontend por fases ordenadas.

## Lectura recomendada

1. lee [`../../../README.md`](../../../README.md)
2. revisa [`../architecture/modular-mvp-architecture.md`](../architecture/modular-mvp-architecture.md)
3. revisa [`../Reference/nomenclatura.md`](../Reference/nomenclatura.md)
4. entra en la guia numerada que corresponda

## Ideas base del proyecto

- `JsonLens` es el frontend del ecosistema
- consume `adminJsonLens` para procesamiento JSON
- sigue arquitectura modular por features
- codigo en ingles
- comentarios y documentacion interna en espanol

## Que tipo de archivos van aqui

Aqui encajan archivos como:

- guias numeradas `01` a `09`
- pasos de construccion por bloques
- documentacion secuencial de implementacion

## Que archivos NO van aqui

No deberian ir aqui:

- reglas generales del proyecto
- referencia de consulta rapida
- decisiones de arquitectura global

Esos documentos encajan mejor en:

- `../Reference/`
- `../architecture/`
