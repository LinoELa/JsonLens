# React and Vite Setup

## Objetivo

Esta guia deja preparada la base minima del frontend para `JsonLens`.

## Que cubre

- inicializar `package.json`
- instalar dependencias base
- dejar configurado Vite con React
- definir scripts de desarrollo y build

## Decision tomada en este proyecto

`JsonLens` usa:

- `React`
- `Vite`
- `JavaScript`
- `ES Modules`

## Dependencias base actuales

- `react`
- `react-dom`
- `vite`
- `@vitejs/plugin-react`

## Puerto recomendado

- frontend `JsonLens`: `5173`
- backend `adminJsonLens`: `5700`

## Resultado esperado de esta fase

Al cerrar esta fase, el proyecto ya debe poder:

- instalar dependencias con `npm install`
- arrancar con `npm run dev`
- generar build con `npm run build`
