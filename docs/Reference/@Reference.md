# @Reference

Esta carpeta guarda documentacion de consulta rapida del frontend `JsonLens`.

## Para que sirve esta carpeta

Sirve para centralizar reglas reutilizables del dia a dia:

- workflow de Git
- codigos HTTP utiles para consumir API
- nomenclatura del frontend
- checklist de "preparar todo"

## Que tipo de archivos van aqui

Aqui encajan archivos como:

- convenciones de ramas y commits
- referencia de codigos HTTP
- reglas de nombres de componentes y carpetas
- checklists tecnicos de cierre

## Que archivos NO van aqui

No deberian ir aqui:

- guias numeradas paso a paso
- decisiones de arquitectura principal

Esos documentos encajan mejor en:

- [`../guides/`](../guides)
- [`../architecture/`](../architecture)
