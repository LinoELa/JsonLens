# MVP JsonLens Frontend

## Resumen

| Aspecto    | Detalle                     |
| ---------- | --------------------------- |
| Aplicación | JsonLens Frontend           |
| Stack      | React, Vite, JavaScript     |
| Enfoque    | Modular por features        |
| Objetivo   | Interfaz para procesar JSON |

## Funcionalidades Core

1. **Validar JSON** — Parsear y validar syntax
2. **Formatear JSON** — Pretty print y minificar
3. **Analizar estructura** — Mostrar árbol de datos
4. **Comparar documentos** — Diff entre dos JSON
5. **Mostrar resultados** — UI clara y responsive

## Features Principales

### json-process  
- Pegar/cargar JSON
- Validar y formatear
- Ver estructura
- Comparar dos documentos

### settings
- Preferencias de formato
- Configuración visual

## Fuera de MVP

- Autenticación
- Historial de búsqueda
- Persistencia de datos
- Exportar reportes
- Colaboración en tiempo real
